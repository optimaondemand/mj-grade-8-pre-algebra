📚 VOCABULARY

Linear Equation: An equation that forms a straight line when graphed and can be written in the form \(ax + by = c\), where \(a\), \(b\), and \(c\) are constants.

Ordered Pair: A pair of numbers written as \((x, y)\) that represent a point's location on a coordinate plane.

Solution to a System of Linear Equations: An ordered pair that satisfies all equations in the system simultaneously, making each equation true when substituted.

System of Linear Equations: A set of two or more linear equations with the same variables that are considered together.

True Statements: Statements or equations that are accurate or valid based on given conditions or values.

💡 EXPLORING THE MATH

In today's lesson, we will explore what a system of linear equations is and how to identify whether an ordered pair is a solution to the system. A system of linear equations is a set of two or more equations that share the same variables. The solution to this system is an ordered pair that makes all the equations true simultaneously. By the end of this lesson, you will understand how to check if a specific ordered pair satisfies a system and how to use substitution to verify solutions in both mathematical and real-world scenarios.


What is a System of Linear Equations?

A system of linear equations consists of two or more linear equations that use the same variables.

For example, the system represents two lines on a graph. The solution is the ordered pair where these two lines intersect, which satisfies both equations.

What Does It Mean for an Ordered Pair to Be a Solution?

An ordered pair is a solution to a system if substituting its \(x\) and \(y\) values into each equation makes all equations true.

For example, is the ordered pair \((-1, 2)\) a solution of the system?

Solution:

  • To check, we will substitute  \(x=-1\) and \(y=2\) into each equation in the system to check for true statements.
    • \(2=2(-1)+3 \implies 2=-2+3 \implies 2=1 \)   False
    • \(2=-(-1)+1  \longrightarrow  2=1+1  \longrightarrow  2=2 \)   True
  • Because the solution does not create a true statement for BOTH equations, the ordered pair is NOT a solution of the system.



How to Identify a Solution Using Substitution

To check if an ordered pair is a solution:

  1. Substitute the \(x\)- and \(y\)-values into each equation.
  2. Simplify and determine if the statements are true for all equations.
  3. If the ordered pair makes all equations true, it is a solution.



Example 1

Given the system shown, which ordered pair is a solution to the system; \(\{(6,8), (4,7), (-2,4), (10,9)\}\).

Solution:

  • We will substitute each ordered pair into the system to see if it creates a true statement for both equations.
  • We will begin with testing the first ordered pair \((6,8)\)
    • \(2(6) - 8 = 4 \implies 12-8=4\)   True
    • \(8=\frac{1}{2}(6)+5 \implies 8=3+5\)   True
  • We see that when we substitute the ordered pair \((6,8)\) into both equations, it creates true statements for both.
  • This means that \((6,8)\) IS a solution of the system.
  • Systems of Linear Equations generally only have one solution unless they are the same line which will have infinite solutions (this will be discussed in another lesson).
  • We will briefly check the other ordered pairs to ensure we did our work correctly.
    • Checking \((4,7)\)
    • \(2(4)-7=4 \implies 8-7=4\)   False
    • Since the first one is false, we can avoid checking it in the second equation since both have to be true.
    • Checking \((-2,4)\)
    • \(2(-2)-4=4 \implies -4-4=4\)   False
    • Checking \((10,9)\)
    • \(2(10)-9=4 \implies 20-9=4\)   False
  • Since the ordered pair \((6,8)\) was the only one that created True statements for BOTH equations, our solution is \((6,8)\).



Example 2

Given the system shown, which ordered pair is a solution to the system; \(\{(2,1),(3,0),(1,2),(4,-1)\}\).

Solution:

  • We will substitute each ordered pair into the system to see if it creates a true statement for both equations.
  • We will begin with testing the first ordered pair \((2,1)\)
    • \(1=-(2)+3 \implies 1=-2+3\)   True
    • \(2(2)+1=7 \implies 4+1=7\)   False
  • We see that when we substitute the ordered pair \((2,1)\) into both equations, it creates a true statement for the first equation but not the second one.
  • So, we will keep testing ordered pairs.
  • Now we will check \((3,0)\)
    • \(0=-(3)+3 \implies 0=-3+3\)   True
    • \(2(3)+0=7 \implies 6+0=7\)   False
  • Now we will check \((1,2)\)
    • \(2=-(1)+3 \implies 2=-1+3\)   True
    • \(2(1)+2=7 \implies 4+2=7\)   False
  • Checking \((4,-1)\)
    • \(-1=-(4)+3 \implies -1=-4+3\)   True
    • \(2(4)+(-1)=7 \implies 8-1=7\)   True
  • Since the ordered pair \((4,-1)\) was the only one that created True statements for BOTH equations, our solution is \((4,-1)\).



Real-World Problem Example

A store sells apples and bananas. An apple costs $2, and a banana costs $1. The total cost of 3 apples and 2 bananas is $8. Another customer buys 5 apples and 1 banana for $11.
The system of equations is:

If the set of ordered pairs that represents different combinations of apples (\(a\)) and bananas is (\(b\)) \(\{(1,4), (2,2), (4,0), (1,6)\}\), then identify which combination of apples and bananas satisfies the system.

Solution:

  • We will substitute each ordered pair into the system to see if it creates a true statement for both equations.
  • We will begin with testing the first ordered pair \((1,4)\)
    • \(2(1)+4=8 \implies 2+4=8\)   False
    • Since the first equation results in a false statement, we do not need to test the second equation.
  • We see that when we substitute the ordered pair \((2,1)\) into both equations, it creates a true statement for the first equation but not the second one. So, we will keep testing ordered pairs.
  • Now we will check \((2,2)\)
    • \(2(2)+2=8 \implies 4+2=8\)   False
  • Now we will check \((4,0)\)
    • \(2(4)+0=8 \implies 8+0=8\)   True
    • \(5(4)+0=11 \implies 20+0=11\)   False
  • Checking \((1,6)\)
    • \(2(1)+6=8 \implies 2+6=8\)   True
    • \(5(1)+6=11 \implies 5+6=11\)   True
  • Since the ordered pair \((1,6)\) was the only one that created True statements for BOTH equations, our solution is \((1,6)\).
  • This means another customer could buy a combination of 1 apple and 6 bananas at the same rates as the other 2 customers.



Conclusion

In this lesson, we introduced systems of linear equations and explored how to determine if an ordered pair is a solution. By substituting values into each equation, we checked whether the pair made all the equations true. We also applied this knowledge to solve real-world problems. Mastering this skill is essential for analyzing relationships between variables and solving practical mathematical challenges.
